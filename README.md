# Стеллаж инструментальный 6000 × 700 × 1800 — чертёж для Visio

Чертёж переработан по сравнению с веб-версией (`alexbae2.github.io/3dked`): вместо HTML-страницы —
настоящий Visio-файл с редактируемыми фигурами, рамкой и основной надписью.

## Файлы

| Файл | Что это |
|---|---|
| `out/stellazh-6000x700x1800.pdf` | 4 листа A3, печатная версия |
| `out/preview/list-1…4.png` | превью листов (150 dpi) |
| `vsd.py` | генератор пакета `.vsdx` (OOXML/OPC: content types, rels, pages, ShapeSheet) |
| `draft.py` | чертёжные примитивы: рамка, основная надпись, размеры со стрелками, позиции, таблицы, штриховка |
| `model.py` | параметры изделия и расчёт масс/заготовок (единый источник цифр) |
| `build.py` | отрисовка четырёх листов |
| `qa.py` | контроль вёрстки: пересечения подписей между собой и с линиями, зазоры, выход за рамку |

Visio-файл `out/stellazh-6000x700x1800.vsdx` лежит в репозитории рядом с PDF.

**Как открыть.** GitHub не показывает `.vsdx` в браузере — файл только скачивается.
Открывать: Visio 2013+ (Windows), Visio для веба (загрузить в OneDrive/SharePoint),
OmniGraffle на macOS или LibreOffice Draw (импорт, без полного редактирования).
Для печати и отправки мастеру удобнее PDF — он открывается в браузере сразу.

Пересобрать из исходников (если правили `model.py` или `build.py`):

```bash
python3 build.py out/stellazh-6000x700x1800.vsdx
```

Нужен Python 3.9+ и Pillow (`pip install pillow`). LibreOffice — только для экспорта в PDF:

```bash
soffice --headless --convert-to pdf out/stellazh-6000x700x1800.vsdx --outdir out
```

## Что учтено по ЕСКД

- рамка с полями 20/5 мм — ГОСТ 2.301;
- основная надпись 185 × 55 мм в правом нижнем углу — по мотивам формы 1 ГОСТ 2.104
  (обозначение, наименование, литера, масса, масштаб, лист/листов, организация);
- масштабы из ряда ГОСТ 2.302; линии толстая/тонкая/штриховая/штрихпунктирная — ГОСТ 2.303;
- размеры: выносные и размерные линии, стрелки, текст над линией, вертикальные — с поворотом
  на 90° (чтение снизу вверх) — ГОСТ 2.307;
- позиции на полках-выносках — ГОСТ 2.316; допуски — ГОСТ 30893.1 (класс mK);
- сварка — ГОСТ 14771-76 (полуавтомат в защитном газе, катет 3 мм, шов 30/100), требования
  к швам — по ГОСТ 2.312 в текстовой форме;
- спецификация и ведомость заготовок — по структуре ГОСТ 2.106 (в виде таблиц на поле чертежа).

Отступления, о которых нужно знать:

- шрифт — Arial, а не ГОСТ 2.304 тип А/Б (в Visio меняется выделением всего текста);
- основная надпись — адаптированная форма 1 (сетка граф упрощена, все обязательные графы есть);
- спецификация — таблица на листе 3, а не отдельный документ по форме 2 ГОСТ 2.106.

## Цифры изделия

- габариты 6000 × 700 × 1800; 3 секции по 2000 на болтах М8;
- 24 ячейки: шаг 500 × 900, свет 432,5 мм (крайние) / 455 мм (средние), высота 855 мм;
- двери 497 × 897 — 24 шт., по 3 петли, замок на каждой;
- уголок 45 × 45 × 4 ГОСТ 8509-93 — 88,8 м; лист 1,5 мм ГОСТ 19903-2015 — 34,1 м²;
- масса ≈ 659 кг (секция ≈ 220 кг), из них металл 644 кг;
- расчёт массы — по чистым размерам и сортаменту, без запаса на сварку и раскрой (добавить 3–5 %).

## Что осталось за кадром (вынесено на лист 3)

- «с ящиками» в задании: выдвижных ящиков нет, только ячейки с дверцами;
- нагрузка на ячейку не рассчитывалась (при > 40 кг/м² днище усиливается рёбрами);
- полок внутри ячеек нет; вопрос о перфорации и держателях — к заказчику.

## Проверка вёрстки

```bash
python3 qa.py          # все листы
python3 qa.py 2        # только лист 2
```

Скрипт считает фактические габариты каждой подписи (с учётом поворота на 90°) и падает,
если две подписи пересекаются, если подпись пересекает линию чертежа, если зазор меньше
0,9 мм или подпись вылезает за рамку 20/5. Сейчас по всем четырём листам — 0 замечаний.
